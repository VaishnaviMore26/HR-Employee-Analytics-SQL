# HR Employee Analytics — SQL Project

## 📌 Project Overview

This project focuses on analyzing employee data to understand workforce distribution, employee attrition, salary patterns, job roles, departments, employee experience, job satisfaction, and other HR-related factors.

**SQL is the primary tool used for database management and analysis**, while Python is used for data cleaning and preparation.

The project demonstrates an end-to-end data analysis workflow using **Python, MySQL, and SQL**.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze employee demographics and workforce distribution
* Understand employee attrition patterns
* Analyze salary distribution across departments and job roles
* Analyze employee experience and job satisfaction
* Identify factors associated with employee attrition
* Compare departments and job roles
* Perform data cleaning and validation
* Use SQL to generate meaningful HR insights
* Practice advanced SQL techniques on a real-world dataset

## 🔍 SQL Analysis

The SQL analysis is divided into four stages.

### 1. Database Setup

**File:** `01_database_setup.sql`

This file contains queries for:

* Creating the database
* Creating tables
* Defining primary keys
* Defining appropriate data types
* Preparing the database for analysis

### 2. Data Cleaning

**File:** `02_data_cleaning.sql`

This file contains queries for:

* Checking NULL values
* Identifying duplicate records
* Checking data consistency
* Validating employee information
* Preparing data for analysis

### 3. Business Analysis

**File:** `03_analysis_queries.sql`

This file contains SQL queries for analyzing:

* Employee count by department
* Employee distribution by job role
* Salary analysis
* Attrition analysis
* Department-wise employee statistics
* Employee experience
* Job satisfaction
* Overtime
* Employee demographics

### 4. Advanced SQL Analysis

**File:** `04_advanced_queries.sql`

This file demonstrates advanced SQL concepts such as:

* Common Table Expressions (CTEs)
* Window Functions
* Subqueries
* CASE statements
* Ranking
* Conditional Aggregation
* Advanced JOINs
* Analytical queries
